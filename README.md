# SCZ-analysis

This repository contains scripts for the '**Spatially resolved translational dysregulation in brain cell types of Grin2a+/- mouse model of schizophrenia**'. 

1. ```preprocessing``` (filtering, integration, cell-type classification, tissue region identification, and grid quantification)
2. ```downsteam analysis``` (cNMF, DE analysis, GSEA, Basal **Grin2a** correlation, and co-variation)

Please refer to the README.md files under each subfolder for more detailed information.
